## 如何使用

1. **照課本順序讀**：先讀 `grade-7/8/9` 各檔，按課讀「一句話主旨 → 重點整理 → 關鍵人物／事件 → 時間軸 → 因果脈絡 → 會考常考點」。
2. **用時間軸橫向對照**：讀完一冊後，對照 `timeline.md`，把同一時期的臺灣、中國、世界連起來，例如 19 世紀：工業革命 → 帝國主義 → 清朝開港通商 → 臺灣開港。
3. **考前用 `exam-points.md` 複習**：先看跨冊連結與易混觀念，再回頭翻各課細節。
4. **自己補筆記**：每課最後都有「我的筆記」留白，建議寫下老師補充、錯題、以及自己會搞混的點。

## 學習方法：三個習慣

- **先問「為什麼」，再背「是什麼」**：每個事件都問：前因是什麼？誰受益、誰受害？結果改變了什麼制度或生活？
- **畫一條線**：每課至少能畫出一條 5–8 個節點的時間線，說得出先後與因果。
- **跨冊連線**：看到一個事件，問它在另外兩冊的同一時期對應什麼，例如甲午戰爭同時連到臺灣割讓（七年級）、清末變局（八年級）、帝國主義（九年級）。

- **版本**：康軒版國中社會・歷史第一至第六冊為準。
- **課綱**：108 課綱。七年級為臺灣史，八年級為中國與東亞史，九年級為世界史。
